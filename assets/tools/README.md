# Оновлення каталогу

Три кроки, виконувати по черзі. Скрипти PowerShell 5.1+, працюють без
`node`/`npm`.

```powershell
# 1. Зібрати сторінки Steam Community Market для Rust (appid 252490).
#    Кожна сторінка = 10 предметів, запити йдуть повільно, щоб не отримати 429.
#    Скрипт можна перезапускати — уже зібрані сторінки пропускаються.
powershell -File assets\tools\01-harvest-market.ps1

# 2. Зібрати assets\data\catalog.js + список іконок imglist.txt.
#    Також друкує зведення по категоріях і цінах.
powershell -File assets\tools\02-build-catalog.ps1

# 3. Завантажити іконки скінів у assets\img\skins\ (128px JPEG).
#    Треба ~25 хв на 4 000 предметів; уже завантажені пропускаються.
powershell -File assets\tools\03-download-icons.ps1
```

Після цього відкрийте `selftest.html` — має бути `0 FAIL`.

## Що робить кожен крок

| Скрипт | Вхід | Вихід |
|--------|------|-------|
| `01-harvest-market.ps1` | Steam Market API | `pages\p0000.json … p0549.json` у тимчасовій теці |
| `02-build-catalog.ps1` | ті самі `pages\` | `assets/data/catalog.js`, `img/imglist.txt`, зведення в консоль |
| `03-download-icons.ps1` | `img/imglist.txt` | `assets/img/skins/<id>.jpg` |

## Налаштування

Усі шляхи — параметри за замовчуванням, подивіться перші рядки кожного файлу:

* `01` — `-Total 5499` (скільки всього предметів на ринку), `-DelayMs 1500`
  (пауза між запитами; збільште, якщо часто отримуєте 429).
* `02` — `-Pages`, `-Project`; правила категоризації — блок `$CAT_RULES`,
  межі рідкості — `$RARITY_STEPS`.
* `03` — `-Size 128`, `-Quality 90`, `-Batch 32`; `-Size 96` дає вдвічі
  менші файли, але картинка розмивається на сторінці деталей.

## Курс валюти

Скрипти не знають про `TX`. Валюта живе у `assets/js/data.js`:

```js
const CURRENCY = { code: 'TX', ... };
const USD_RATE = 10000;
```

`catalog.js` містить ціну в USD, а `data.js` перераховує її в `TX`
при завантаженні. Тому змінити курс можна без перебудови каталогу.

## Чому JPEG, а не PNG

Іконки скінів приходять з прозорістю, PNG 128px важить ~13 КБ. Після
накладання на колір тла предмета (`background_color` зі Steam) і
збереження в JPEG 90 — ~2 КБ. Для 4 000 предметів це 16 МБ замість 52 МБ,
що важливо для папки в OneDrive.

# RUSTGRADE

Статичний клон rustgrade.com — маркетплейс предметів Rust з апгрейдером.
Вхід **за власним ключем**, без Steam OAuth. Працює з подвійного кліку по
`index.html` — жодного `npm`, `node` чи сервера не потрібно.

Каталог — **справжні предмети Rust зі Steam Community Market**: реальні назви,
реальні ринкові ціни в USD, реальні іконки скінів. Усього **4 166 предметів**.

---

## Запуск

```
start.bat          # або просто двічі клацнути index.html
```

Відкриється `file:///.../Default%20Project/index.html`.

## Каталог: справжні предмети Rust

Каталог **не вигаданий**. Він зібраний зі Steam Community Market для Rust
(`appid=252490`) і лежить у `assets/data/catalog.js` (~5 500 предметів).

Для кожного предмета зберігається:

| Поле     | Що це                                            |
|----------|--------------------------------------------------|
| `name`   | справжня назва скіна (`No Mercy Revolver - E Class`) |
| `usd`    | справжня ціна продажу на Steam Market             |
| `cat`    | категорія, визначена за назвою                    |
| `rarity` | рідкість, визначена за ціною                      |
| `bg`     | справжній колір тла предмета (`background_color`) |
| `listings`| кількість пропозицій на Steam Market              |
| `img`    | `assets/img/skins/<id>.jpg` — справжня іконка      |

Формат запису мінімальний, щоб файл завантажувався швидко:

```js
["6TMcQ7eX6E0E5460781770","No Mercy Revolver - E Class",1295.38,"pistol","exotic","42413e",12]
```

Альтернативно можна сортувати за популярністю — на реальному маркеті це
кількість активних пропозицій.

### Як оновлювати каталог

1. Зібрати сторінки Steam Market (по 10 предметів на запит).
2. Прогнати `build.ps1` — він здедуплікує, категоризує, порахує рідкість
   і запише `assets/data/catalog.js` + список іконок.
3. Завантажити іконки — скрипт бере `128fx128f` із CDN Steam, накладає їх на
   колір тла предмета і зберігає JPEG (1.8 КБ замість 13 КБ у PNG).
4. Прогнати `selftest.html` — має бути `0 FAIL`.

Усі три скрипти лежать у `assets/tools/`.

## Валюта і ціни

Єдине місце для зміни валюти — `CURRENCY` на початку `assets/js/data.js`:

```js
const CURRENCY = { code: 'TX', name: 'TX', decimals: 0 };
```

Ціна в ігровій валюті — це **справжня ціна в USD помножена на курс**:

```js
const USD_RATE = 10000;   // $10.09  ->  100 900 TX
```

На картці під ціною показується справжня ціна в доларах, на сторінці деталей —
ще й підпис «Справжня ціна на Steam Market». Змінити курс можна в одному
місці; щоб відірвати ціни від ринку — об'єкт `REAL_PRICES` у `data.js`.

Рідкість теж походить із ціни (`RARITY_BY_USD` у `data.js`):

| USD        | Рідкість     |
|------------|--------------|
| < 0.30     | Звичайний    |
| < 1        | Непоширений  |
| < 5        | Рідкісний    |
| < 20       | Незвичайний  |
| < 75       | Епічний      |
| < 250      | Легендарний  |
| ≥ 250      | Екзотичний   |

Валюта **повністю внутрішня**: виведення в реальні гроші не реалізовано
і не передбачене.

## Промокоди

> Назва жодного промокоду **ніде не показується**: немає банерів, окремої
> сторінки, згадок у підвалі чи в навігації. Є лише порожнє поле
> «Промокод» у гаманці — користувач сам вводить код, який йому видали.

**Як роздавати коди:**

1. Увійдіть за будь-яким ключем.
2. Відкрийте `#/admin` — посилання на цю сторінку немає ніде в інтерфейсі.
3. Вкажіть суму (за замовчуванням 100 000), код або натисніть «Інший»
   для генерації, нотатку («для Івана з Discord») і опцію «один раз на акаунт».
4. Скопіюйте код і дайте його потрібній людині.

Коди зберігаються у `localStorage` цього браузера (`rgx_promos`) —
**видаляються разом із даними браузера**. Це локальна демо-роздача, не сервер.

Вбудований код (100 000, один раз на акаунт) прописаний у `PROMO_CODES`
у `data.js` і не згадується в жодному розділі інтерфейсу.

## Вхід і свої акаунти

Пароль **довільний** — це не обов'язково `RG-XXXX-XXXX-XXXX-XXXX`. Можна
написати «дракон», «Drakon 2010», «12345», будь-які літери, цифри та пробіли.
Мінімум 3 символи, максимум 32. Регістр має значення: `Дракон` і `дракон` —
це два різні акаунти.

Сторінка `#/login` має дві вкладки.

**«Увійти»** — вводите свій пароль. Якщо акаунтів уже створювали в цьому
браузері, внизу з'являється список **«Мої акаунти»**: натисніть на рядок, щоб
увійти миттєво, без введення пароля. Такий самий список є на екрані
«Ви авторизовані», де ще й видно ваш власний ключ. Нижче — демо-ключі для
прикладу.

Якщо ввести неправильний пароль, акаунт **не створюється** — показується
помилка з підказкою перейти на вкладку реєстрації. Так випадково не подаруєте
собі порожній акаунт через помилку в великій літері. Єдиний виняток: ключ
вигляду `RG-XXXX-XXXX-XXXX-XXXX` створює акаунт автоматично, як раніше.

**«Створити акаунт»** — вводите ім'я і пароль (або залишаєте пароль порожнім і
тиснете «Ключ», тоді згенеруємо `RG-XXXX-XXXX-XXXX-XXXX`). Акаунт пишеться у
браузер і ви одразу авторизовані. Після цього пароль показується великим
блоком із кнопкою копіювання — **запам'ятайте його**: відновити неможливо.

Слова `__proto__`, `prototype`, `constructor` заборонені як пароль: вони
ламають об'єкт сховища. Решта — будь-яка.

Акаунти не заважають один одному: їх можна скільки завгодно, перемикайтеся
кліком по рядку у списку. Кожен має свій баланс, інвентар, історію та
активовані промокоди.

Новому акаунту дається стартовий інвентар — найдешевші предмети з основних
категорій, щоб було з чим апгрейдити. Баланс нового акаунта — 0.

> **Чесне застереження.** Це локальний сайт без сервера. Паролі лежать у
> `localStorage` відкритим текстом — їх бачить будь-хто, хто відкриє DevTools
> на цьому комп'ютері. Для іграшки з друзями це нормально; для грошей —
> ні. Не вводьте туди пароль від пошти чи від справжнього Steam.

Демо-ключі (видно на сторінці входу):

| Ключ                    | Ім'я      | Баланс     |
|-------------------------|-----------|------------|
| `RG-DEMO-0000-0000-0000` | DemoUser | 500 000    |
| `RG-TEST-0000-0000-0001` | TestUser | 2 500 000  |

Стан зберігається у `localStorage`: `rgx_session`, `rgx_accounts`, `rgx_promos`.
Ключ акаунта — це ім'я поля в об'єкті `rgx_accounts`, тому довільний пароль
може містити пробіли, апострофи та лапки без проблем.

## Самоперевірка

Відкрийте `selftest.html` у браузері. Очікувано `=== 72 PASS / 0 FAIL ===`.

Перевіряється: індексація каталогу, відповідність ціни USD→TX, наявність
іконки в кожного предмета, формат ключів, логін, активація промокоду (сума і
повторний заблокований), купівля, продаж із комісією 10%, відсутність мутацій
при відхиленій операції, межі шансів апгрейду, створення/видалення промокодів
в адмінці, HTML-елювання.

## Чесні обмеження

* **Ролли апгрейду — клієнтський `Math.random`.** Це демонстрація механіки;
  будь-який, хто відкриє DevTools, може підкрутити результат. Для справжньої
  гри потрібен сервер із генератором імовірностей на сервері.
* **Промокоди живуть у `localStorage`** — це прихована адмінка для ручної
  роздаці, а не захищена система. Видалення даних браузера стирає коди.
* **Немає сервера.** Немає ані бази, ані реального обміну предметами між
  гравцями, ані виведення валюти в гроші.
* **Ціни — знімок Steam Market на момент збору.** Вони не оновлюються самі;
  для свіжих цін треба прогнати `assets/tools/` ще раз.

# Месенджер (у стилі Discord) — повністю робоча програма

Локальний багатокористувацький месенджер: сервери, канали, прямі повідомлення,
друзі, ролі, реакції, пошук, голосові канали (WebRTC) та **безкоштовний Nitro**.
Інтерфейс українською. Уся графіка й код — оригінальні.

## Запуск як програма

Це **настільна програма**, а не сайт у вкладці браузера: вона відкривається у
власному вікні без адресного рядка й вкладок, зі своєю іконкою в панелі задач.

1. Потрібен Node.js 18+ (перевірено на v24).
2. Двічі клікніть **«Месенджер»** на робочому столі (ярлик створюється автоматично)
   **або** `start.bat`, **або** `launch.vbs`.

`launch.vbs` тихо піднімає локальний сервер і відкриває вікно застосунку
(Edge/Chrome у режимі `--app`). Коли вікно закривається, сервер **сам зупиняється**
(режим `--app`), тож у фоні нічого не залишається.

- Ярлик у папці: `Месенджер.lnk`; на робочому столі: `Месенджер.lnk`.
- Щоб створити ярлики заново — запустіть `create-shortcut.ps1`.

Якщо потрібен «чистий» сервер без вікна (наприклад, для кількох людей у мережі):

```
node server.js
```

База даних і завантажені картинки лежать у папці `data/` (створюється автоматично).
Щоб скинути все — видаліть `data/`.

> **Про `.exe`.** У комплекті є вихідник `launcher.cs` і скрипт `build-exe.ps1`,
> які збирають самодостатній `Messenger.exe`. На цьому комп’ютері політика
> контролю застосунків блокує запуск саморобних `.exe`, тому штатний запуск —
> через `launch.vbs` (той самий результат: окреме вікно-програма).

## Можливості

- **Акаунти**: реєстрація, вхід, сесії (токени), хеш пароля `scrypt`.
- **Сервери**: створення, іконка, категорії, текстові та голосові канали.
- **Канали**: створення/перейменування/видалення, тема, позначення прочитаним.
- **Повідомлення**: надсилання, редагування, видалення, відповіді, групування,
  роздільники дат, вкладення-зображення, реакції, закріплення.
- **Markdown**: `**жирний**`, `*курсив*`, `__підкреслення__`, `~~закреслення~~`,
  `` `код` ``, багаторядковий код, цитати `>`, спойлери `||текст||`, посилання,
  згадки `@користувач`, `@everyone`, `@here`, `#канал`.
- **Друзі**: запити, прийняття, видалення, блокування, прямі повідомлення.
- **Реальний час**: Server-Sent Events (SSE) — нові повідомлення, реакції,
  індикатор набору тексту, статуси присутності, оновлення серверів.
- **Голос**: голосові канали через WebRTC (аудіо P2P), сигналінг через сервер,
  мікрофон, звук, від'єднання.
- **Ролі**: створення ролей з кольором і правом «Керування», видача учасникам.
- **Пошук**: по серверу або у прямих повідомленнях.

## Nitro — безкоштовно

Вкладка **Nitro** (у налаштуваннях або в бічній панелі ЛС) вмикає безкоштовно:

- банер профілю;
- великий/анімований аватар;
- тег до 4 символів біля імені;
- бейдж `NITRO` у чаті;
- завантаження файлів до **10 МБ** (замість 4 МБ);
- повідомлення до **4000** символів (замість 2000).

Керується на сервері полем `user.nitro`; права й ліміти перевіряються на бекенді.

## Структура

```
discord/
├─ server.js            # бекенд: HTTP + SSE + REST, без npm-залежностей
├─ package.json
├─ launch.vbs           # запускник програми (без консолі)
├─ start.bat            # викликає launch.vbs
├─ create-shortcut.ps1  # створює ярлики «Месенджер»
├─ icon.ico             # іконка застосунку
├─ launcher.cs          # вихідник самодостатнього .exe (опційно)
├─ build-exe.ps1        # збірка Messenger.exe (опційно)
├─ data/                # база даних і завантаження (створюється автоматично)
└─ public/
   ├─ index.html
   ├─ css/app.css
   └─ js/
      ├─ icons.js       # оригінальні SVG-іконки
      ├─ ui.js          # DOM-хелпери, модалки, меню, markdown
      ├─ core.js        # стан, API, SSE, роутер, статуси
      ├─ voice.js       # WebRTC-голос
      ├─ chat.js        # вікно чату
      └─ views.js       # сервери, канали, друзі, профіль, налаштування
```

## Технології

- Бекенд: Node.js (`http`, `crypto`), власний роутер, SSE для реального часу,
  JSON-база з атомарним записом (`data/db.json`).
- Фронтенд: ванільний JavaScript, без фреймворків і збірки.
- Голос: WebRTC (`RTCPeerConnection`) зі STUN Google, сигналінг через SSE.

## Примітки

- Це навчальний клон: названі функції відтворюють логіку популярного
  месенджера, але використовують лише оригінальні код і графіку.
- Голос у локальній мережі працює через STUN; для роботи за NAT потрібен
  власний TURN-сервер (не входить у комплект).
